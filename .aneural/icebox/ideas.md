# Icebox

## Symbol-level nodes
Exported classes/functions as `Symbol` nodes with `REFERENCES` edges from call sites (tree-sitter queries exist; needs an id scheme and a size cap).

## HTTP transport for the MCP server
So claude.ai connectors can use Aneural remotely; the tool surface stays the same.

## WASM spores
Sandboxed harvesters for the marketplace once the declarative kinds run out of steam. See [[Spores]].

## Layout persistence
Save pinned positions to `state/layout.json` so the mycelium looks the same tomorrow.
